# 天坛协作扩展变量架构（第二层）

## 目的

在不破坏第一版最小变量集的前提下，增加适合多中心神经影像、神经外科和专病队列协作的变量。第二层变量用于机制探索、模型增益评估和外部验证；不是所有患者都必须具备。

## 分层原则

- **MVP 层：** 所有入组患者必须尽可能具备的 20 个核心变量。
- **协作层：** 有条件中心或子队列收集，用于提高可解释性和泛化能力。
- **研究层：** 组学、影像组学和实验数据，仅在预设问题、质量控制和样本量支持时使用。

## A. 影像与解剖扩展

| 变量组 | 建议字段 | 价值 |
| --- | --- | --- |
| 原始影像元数据 | MRI 日期、设备厂商、磁场强度、序列、层厚、对比剂 | 识别中心/设备差异，保证可复现性 |
| 结构化肿瘤测量 | 三轴径、体积、鞍上/鞍旁扩展、Knosp 分级、颈动脉包绕 | 比单一直径更完整地描述侵袭与手术难度 |
| 周边结构 | 视交叉距离/受压、垂体柄、正常腺体、海绵窦与颈内动脉关系 | 连接解剖风险、功能损害和手术结局 |
| 影像组学候选 | 仅保存经版本控制的特征提取版本、ROI 规则和质控结果 | 用于探索；不得替代原始影像审计 |

## B. 手术与围术期扩展

| 变量组 | 建议字段 | 价值 |
| --- | --- | --- |
| 手术复杂度 | 入路、术者/团队编码、手术时长、出血量、重建方式 | 区分肿瘤风险与治疗过程差异 |
| 术中发现 | 海绵窦受累、肿瘤质地、出血、可见残留原因 | 为影像与结局提供临床解释 |
| 早期并发症 | 脑脊液漏、尿崩、激素轴功能、再入院 | 衡量干预代价，避免只优化肿瘤控制 |
| 病理流程 | 固定方式、检测平台、报告日期、阅片者/复核状态 | 判断跨中心病理差异 |

## C. 内分泌与患者结局扩展

| 变量组 | 建议字段 | 价值 |
| --- | --- | --- |
| 激素时间序列 | 每次检测日期、分析平台、单位、参考区间、用药状态 | 允许建模动态反应而非单一数值 |
| 垂体功能 | 各激素轴缺乏、替代治疗、剂量与开始/停止日期 | 与生活质量和长期风险直接相关 |
| 视功能 | 视力、视野检查方法与日期 | 体现临床获益，不只看肿瘤体积 |
| 患者报告结局 | 症状、疲劳、睡眠、认知、生活质量量表及版本 | 让模型对患者真正重要的结局负责 |

## D. 分子与机制研究层

| 变量组 | 建议字段 | 使用边界 |
| --- | --- | --- |
| 扩展病理 | 转录因子、受体、增殖与 DNA 修复相关标记 | 先保证检测与判读一致性 |
| 遗传/表观遗传 | 检测方法、版本、变异注释、肿瘤/正常样本来源 | 仅在合规、样本量充分时进入模型 |
| 转录组/单细胞/空间数据 | 样本处理时间、批次、平台、质控指标 | 首先做机制和亚型探索，不直接临床部署 |
| 类器官/药敏数据 | 建模成功率、实验条件、药物浓度、读出指标 | 用于提出可验证治疗假设 |

## E. 多中心协作与泛化变量

| 变量 | 原因 |
| --- | --- |
| `site_id`（脱敏中心编码） | 检验模型是否过度依赖单中心习惯 |
| 诊断/手术/随访年份 | 处理技术和治疗标准随时间改变 |
| 数据来源与提取方式 | 区分手工抽取、电子病历、影像系统和研究数据库 |
| 缺失原因 | 区分未检测、不可获得、患者失访和数据提取失败 |
| 标签裁决状态 | 标记结局是否经独立复核 |

## 协作时必须先统一的 6 件事

1. 预测时间点与主要结局的统一定义。
2. MRI 采集和侵袭判读的最小标准。
3. 激素名称、单位、检测方法与参考区间的映射表。
4. 病理分型、复核和不确定性记录规则。
5. 数据脱敏、访问、导出与代码运行边界。
6. 外部验证、作者贡献、知识产权和结果发布规则。

## 建模策略

先比较“20 个核心变量”的基线模型与“核心 + 协作层变量”的增益；只有增益在独立中心仍然稳定、且不牺牲公平性与可解释性时，才保留复杂变量。

任何真实患者数据进入本项目之前，均需要相应伦理审批、数据使用授权和安全环境；不得上传到公开 GitHub 仓库。
